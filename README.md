# 简易个人网站

已在本仓库创建一个简易的单页个人网站（分支 add-simple-site）：

- index.html
- styles.css

如何查看和部署：

1. 在 GitHub 上切换到分支 `add-simple-site`。
2. 若要使用 GitHub Pages：进入仓库 Settings -> Pages，选择 `add-simple-site` 分支并保存，几分钟后即可访问。
3. 若要自定义：编辑 `index.html` 中的姓名��简介、项目、联系方式，以及 `styles.css` 以修改样式。

如果你想我把网站合并到默认分支（例如 main）或使用 `gh-pages` 分支发布，请回复我，我可以继续操作。
